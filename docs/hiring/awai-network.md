# Awai network の募集要項（この board の運営者自身の求人）

このページは、`cloud-itonami-isic-6399` の求人 board を運営している
**Awai network** 自身の求人票です。board 上の他の掲載（`gh-*` / `lv-*` の id
を持つもの）は各企業の公式求人ボードから ToS 準拠で収集した第三者の求人ですが、
このページの2件は `:source "employer-direct"` の**自社求人**です。

掲載は他の求人と同じ経路を通ります — `:posting/ingest` →
`:jurisdiction/assess`（職業安定法5条の4 的確表示義務の評価）→
`:posting/publish`（Job Search Portal Governor の HARD check + 人間承認）。
自社求人だからといって governor を迂回しません。

## 募集主体について（先に読んでください）

**Awai network は米国デラウェア州法人（Stripe Atlas により設立）です。**
日本国内に事業所を持たないため、この募集には以下の**構造上の制約**があります。
これは条件を悪くするための方針ではなく、取れる形態がそれしかないという事実です。

- **すべて業務委託です。雇用（正社員・アルバイト・パート）ではありません。**
  労働者派遣・有料職業紹介はいずれも日本では厚生労働大臣の許可制で、国内に
  事業所を持つことが前提になります。当社はその要件を満たさないので、
  派遣や職業紹介の形態は最初から選択肢にありません。
- **第三者企業に常駐して、その企業の指示で働く形にはしません。**
  業務委託の形で第三者の指揮命令下に人を置くことは偽装請負に当たります。
  現地作業は **Awai network 自身の案件**（自社の機材・自社の拠点）に限ります。
- **労働基準法上の労働者としての保護は適用されません。** 最低賃金・残業割増・
  有給・社会保険・雇用保険はいずれも対象外です。指揮命令ではなく成果・タスク
  単位の受発注になります。雇用形態での就業を希望される場合、この募集は適合しません。
- **報酬は米国法人からの支払いになります。** 受取方法（国内送金か海外送金か）・
  為替・着金手数料の負担・支払サイクルは契約時に個別に明示します。米国側の
  税務書類（W-8BEN 等）の提出をお願いする場合があります。日本での所得の申告は
  ご自身で行っていただく前提です。

この2件目は **まだ board に掲載されていません**。報酬額（1件あたりの定額）が
確定していないため、`:compensation-verified? false` として actor に投入され、
governor が publish を保留しています（board の「自社求人 — 報酬額の確定待ち」欄に
その判定が表示されます）。金額が確定した時点で掲載に切り替わります。報酬額を
伏せたまま掲載することは的確表示義務の趣旨に反するため、意図的にこの状態に
しています。

## 応募方法

GitHub の issue で受け付けます:

- **[応募フォーム（GitHub issue）を開く](https://github.com/cloud-itonami/cloud-itonami-isic-6399/issues/new?template=job-application.yml)**

応募内容は public な issue に残ります。氏名・住所・電話番号・生年月日などの
個人情報は issue に書かないでください（この actor は設計上、応募者の
raw PII を保存するスキーマフィールドを一切持ちません — `docs/adr/0001-architecture.md`）。
連絡先は issue のやり取りの中で必要最小限を非公開の経路に切り替えて交換します。

## この求人票の位置づけ

- 実際の契約締結（電子署名）と報酬の支払いは、この board の actor が
  自動で行うものではありません。actor が持つのは掲載判断の統治
  （的確表示・差別的表示の検査・掲載/掲載終了の台帳）だけです。
  設計上の扱いは superproject の ADR-2607269000（proposed）にあります。
- 掲載終了は `:posting/delist` で行い、募集が終了した求人を board に
  残しません（的確表示義務）。
