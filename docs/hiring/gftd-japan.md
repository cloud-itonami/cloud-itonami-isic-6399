このページは、`cloud-itonami-isic-6399` の求人 board の運営側が出している
**日本向けの自社求人**です。board 上の他の掲載（`gh-*` / `lv-*` の id を持つもの）は
各企業の公式求人ボードから ToS 準拠で収集した第三者の求人ですが、このページの2件は
`:source "employer-direct"` の自社求人です。

掲載は他の求人と同じ経路を通ります — `:posting/ingest` → `:jurisdiction/assess` →
`:posting/publish`（Job Search Portal Governor の HARD check + 人間承認）。
自社求人だからといって governor を迂回しません。

## 募集主体（先に読んでください）

**募集主体は `Gftd Japan株式会社`（日本法人）です。**

同じ運営体には米国側の法人 `AWAI Network, L.L.C.`（デラウェア州 LLC）もありますが、
**日本国内で人を雇う・業務委託する・現地作業を回す主体は Gftd Japan株式会社**と

Gftd Japan株式会社です。米国法人が日本在住の方と直接契約する形は取りません。

## この募集の性質

- **業務委託です。雇用（正社員・アルバイト・パート）ではありません。** 指揮命令では
  なく、成果・タスク単位の受発注になります。労働基準法上の労働者としての保護
  （最低賃金・残業割増・有給・社会保険・雇用保険）は適用されません。雇用形態での
  就業を希望される場合、この募集は適合しません。
- **労働者派遣ではありません。** 第三者企業に常駐して、その企業の指示のもとで働く形
  にはしません（業務委託の形で第三者の指揮命令下に人を置くことは偽装請負に当たります）。
  現地作業は**当社自身の案件**（自社の機材・自社の拠点）に限ります。
- この募集は **フリーランス新法（特定受託事業者に係る取引の適正化等に関する法律）**の
  適用を受ける業務委託の募集です。同法12条の的確表示義務に沿って、業務の内容・
  従事する場所・期間・時間・報酬・契約の解除に関する事項を以下に記載しています。
  取引条件は契約時に書面（電子的方法を含む）で明示し、報酬は同法の定める支払期日
  （役務の提供を受けた日から60日以内）を守ります。
