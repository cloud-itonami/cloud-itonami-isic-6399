# 自社求人の募集要項

- **[gftd-japan.md](gftd-japan.md)** — 日本向け（業務委託）。募集主体は
  `Gftd Japan株式会社`。

## 履歴

2026-07-26 に `awai-network.md`（募集主体 `AWAI Network, L.L.C.`）として公開したが、
同日中に募集主体を `Gftd Japan株式会社` へ変更し `gftd-japan.md` に置き換えた。
理由は superproject の ADR-2607269500: 日本国内で人を雇う・業務委託する主体は
日本法人（Gftd Japan株式会社）とし、米国法人（AWAI Network, L.L.C.）は米国側の
principal に限る、と決めたため。日本に事業所を持たない米国 LLC は日本国内の雇用・
派遣を組めず、掲載名義と実際の契約相手が食い違う状態を残せない（フリーランス新法
12条は「実際に業務委託を行う事業者と別の事業者名で募集情報を掲載する」ことを
虚偽表示の例として挙げている）。
